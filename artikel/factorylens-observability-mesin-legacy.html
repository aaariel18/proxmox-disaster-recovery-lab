FACTORYLENS / OBSERVABILITY

Mesin lama tetap bisa punya cerita yang terbaca.

Mesin dapat bekerja bertahun-tahun tanpa API modern. FactoryLens mengeksplorasi cara mencatat apa yang terjadi melalui kamera, suara, sinyal mesin, dan bukti berbasis event.

Observability untuk mesin tanpa API

FactoryLens adalah proyek open-source tahap awal untuk menyatukan informasi yang sering tersebar: CCTV, sinyal PLC, catatan operator, dan konteks proses. Tujuannya adalah membuat timeline mesin yang memiliki referensi ke snapshot, video, audio, dan metadata.

Pre-alpha, bukan sistem keselamatan

Repositori menyatakan pemasangan kamera fisik pertama sudah dilakukan, tetapi validasi siklus machining nyata masih diperlukan. Demo tanpa perangkat memakai sinyal simulasi. FactoryLens bukan pengganti interlock, emergency stop, guarding, atau PLC safety logic.

Dari catatan operator ke bukti satu siklus

Alur utama yang didokumentasikan menghubungkan gesture tiga jari, rekaman voice note operator, transkripsi, normalisasi konteks material/proses, sinyal mesin yang stabil, dan perekaman bukti.

Snapshot bawaan pada jalur perangkat lunak dijadwalkan pada awal siklus, lalu +2 dan +10 detik. Jadwal ini merupakan perilaku yang didokumentasikan, bukan laporan keberhasilan field test.

Mencoba demo tanpa kamera atau CNC

Gunakan environment terisolasi dengan Python 3.11 atau lebih baru. Tinjau dependency proyek sebelum memasangnya. Demonstrasi berikut menghasilkan event simulasi, bukan bukti proses machining nyata.

git clone https://github.com/aaariel18/factorylens.git
cd factorylens
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python examples/prelaunch_demo.py

Di Windows, aktivasi virtual environment menggunakan .venv\Scripts\activate. Demo menyimpan timeline.jsonl dan manifest.json di direktori data demonstrasi yang dijelaskan dalam README.

Apa yang sudah ada di jalur software?

README mendokumentasikan model event dan sesi, RTSP frame capture dengan reconnect, CLI validasi kamera, gesture trigger, perekaman voice note berbatas durasi, antarmuka speech-to-text, normalisasi konteks, serta debounced machine-cycle trigger.

Recorder mengelompokkan konteks mesin/job dan bukti ke satu manifest. Asal sinyal dibedakan sebagai measured, inferred, atau simulated agar pembaca tidak menyamakan simulasi dengan pengukuran mesin.

Apa yang masih perlu divalidasi?

  • Stabilitas RTSP sepanjang siklus machining nyata.
  • Akurasi gesture pada pemasangan kamera yang sebenarnya.
  • Kualitas mikrofon, pengaturan silence stop, dan transkripsi.
  • Pemetaan sinyal running serta konfigurasi adapter mesin.
  • Bundle bukti lengkap dari satu siklus nyata.
  • Mounting, getaran, collision clearance, ROI, dan jalur kabel.

Adapter konkret Modbus/OPC UA/GPIO, dashboard, dan beberapa kemampuan lain masih tercantum sebagai pekerjaan lanjutan. Jangan mengasumsikan seluruh integrasi industrial sudah siap production.

Prinsip yang dipertahankan

Legacy-first: tetap berguna tanpa cloud API. Event-first: observasi penting memiliki timestamp. Evidence-first: event terhubung ke bukti. Edge-friendly: pemrosesan lokal menjadi jalur utama bila memungkinkan.

Credential RTSP, akun kamera, daftar IP internal, rekaman production, audio operator, transkrip, dan file environment tidak boleh dimasukkan ke repositori publik. Tetapkan persetujuan, akses, serta retensi sebelum merekam aktivitas operator.

FactoryLens mengamati dan mencatat. Kendali mesin harus tetap eksplisit dan terisolasi.
